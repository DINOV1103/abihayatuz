Bir martalik sozlash

Admin panel ishlashi uchun Supabase ulash kerak. Bu 10 daqiqa oladi.

  1. supabase.com da yangi loyiha oching (bepul tarif yetadi).
  2. Pastdagi SQL'ni nusxalang. Ichidagi SIZNING_EMAIL@gmail.com ni o‘z emailingizga almashtiring.
  3. Supabase → SQL Editor → New query → SQL'ni qo‘ying → Run.
  4. Authentication → Users → Add user: o‘sha email va parol bilan foydalanuvchi yarating ("Auto confirm" yoqilgan bo‘lsin).
  5. Authentication → Sign In / Providers: "Allow new users to sign up" ni o‘chiring.
  6. Project Settings → API dan Project URL va anon public kalitni oling. Ularni admin.html dagi SUPA_URL va SUPA_KEY qatorlariga hamda index.html boshidagi ABH_SUPA ga yozing.

Faqat admin uchun.
